# Population Calculator
This is a tool to simulate population growth in a place for worldbuilding purposes at a basic level, while still maintaining a good level of detail.

The tool is still very much WIP, although it's currently proven to be able to successfully import the files it needs to work.

It will be run from a command line. I am not going to create a GUI, especially not in Java, even more so if the tool doesn't need one to begin with.
